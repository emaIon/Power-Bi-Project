## Project Overview
This Power BI mock project focuses on analyzing retail sales performance, customer behavior, product trends, and store performance using a fictional retail dataset.
The main goal was to transform raw Excel data into meaningful business insights through interactive dashboards and visualizations.

Throughout this project, I worked on data cleaning and transformation using Power Query, data modeling, creating DAX measures to calculate key performance indicators (KPIs), and designing interactive reports.
The report allows users to monitor sales performance, compare products and stores, analyze customer demographics, and explore sales trends over time.

## Dataset
The dataset covers 2022–2023 and includes:
•	2,287 sales records
•	36 customers
•	5 products
•	4 stores

## Tools & Technologies
Power BI Desktop | Power Query | DAX | Excel

## Report Pages
The report contains 8 interactive pages:
•	Home: Main navigation page.
•	Info: Project overview, dataset information, and KPI explanations.
•	Dashboard: Overview of business performance and key metrics.
•	Sales: Sales trends, revenue, and transaction analysis.
•	Product: Product performance, sales by category, quantities sold, and average spending.
•	Customer: Customer demographics, purchasing behavior, and sales distribution.
•	Store: Store performance comparison, revenue, transactions, and geographical analysis.
•	Self-Service BI: Interactive exploration of sales using a decomposition tree.

## Key Performance Indicators
•	Total Sales
•	Total Quantity Sold
•	Number of Transactions
•	Unique Customers
•	Average Spend per Transaction
•	Average Sales Amount
